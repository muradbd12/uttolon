Teacher-এর ছবিসহ পাবলিক প্রোফাইল সিস্টেম যোগ হলো। এতে প্রথমবারের মতো
Firebase-এর একটা নতুন অংশ (Storage — ছবি রাখার জায়গা) ব্যবহার হচ্ছে,
তাই একটা নতুন সেটআপ ধাপ আছে। এটা firebase-admin-এর মতো জটিল না
(শুধু ব্রাউজার থেকে সরাসরি ব্যবহার হয়), তবু ধাপগুলো ভালোভাবে করুন।

=========================================================
ধাপ ১ — Firebase Storage চালু করুন
=========================================================
1. console.firebase.google.com -এ uttolon প্রজেক্টে ঢুকুন
2. বাম পাশে Build -> Storage
3. "Get started" চাপুন
4. "Start in production mode" বেছে "Next", তারপর একটা location বেছে
   "Done" চাপুন

=========================================================
ধাপ ২ — Storage-এর নিজস্ব Rules বসান (Firestore Rules থেকে আলাদা)
=========================================================
Storage পেজে "Rules" ট্যাবে গিয়ে সব মুছে এটা বসিয়ে Publish করুন:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /teacher-photos/{fileName} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

(এখানে write-এর জন্য শুধু "লগইন করা থাকা" লাগবে — কারণ Storage
Rules থেকে Firestore-এর role চেক করা জটিল ও কম নির্ভরযোগ্য, তাই এই
সহজ সংস্করণটা বেছে নেওয়া হলো। বাস্তবে শুধু Admin panel থেকেই ছবি
আপলোডের কোনো উপায় আছে, তাই এটা যথেষ্ট নিরাপদ।)

=========================================================
ধাপ ৩ — ফাইল বসান
=========================================================
এই zip-এর সব ফাইল (৭টা) Merge/Replace করে বসান।

=========================================================
কীভাবে ব্যবহার করবেন
=========================================================
1. আগে /admin/users থেকে শিক্ষকের লগইন অ্যাকাউন্ট বানান (যদি না
   থাকে)
2. Admin Dashboard -> "শিক্ষক" কার্ডে এখন ২টা লিংক — "পরিচালনা করুন"
   (লগইন অ্যাকাউন্ট) আর "পাবলিক প্রোফাইল" (নতুন)
3. "পাবলিক প্রোফাইল"-এ গিয়ে সেই শিক্ষককে বেছে নিয়ে ছবি (২ MB পর্যন্ত),
   প্রতিষ্ঠান, বিভাগ, অভিজ্ঞতা, পরিচিতি দিন
4. "Publish করুন" চাপলেই /teachers পেজে ও হোমপেজে দেখা যাবে

=========================================================
টেস্ট করবেন যেভাবে
=========================================================
একজন শিক্ষকের প্রোফাইল Publish করার পর /teachers পেজে গিয়ে ছবি ও
তথ্য ঠিকমতো দেখাচ্ছে কিনা দেখুন। ছবি না দেখালে ধাপ ১-২ ঠিকভাবে করা
হয়েছে কিনা যাচাই করুন।
