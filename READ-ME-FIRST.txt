=========================================================
ধাপ ১ — Firestore Database চালু করুন
=========================================================
1. console.firebase.google.com -এ uttolon প্রজেক্টে ঢুকুন
2. বাম পাশে Build -> Firestore Database
3. "Create database" চাপুন
4. Location হিসেবে যেকোনো কাছাকাছি region বেছে "Next"
5. "Start in production mode" বেছে "Create" চাপুন

=========================================================
ধাপ ২ — Security Rules বসান (জরুরি — নইলে সব বন্ধ থাকবে)
=========================================================
Firestore Database পেজে "Rules" ট্যাবে যান, সব মুছে এটা বসিয়ে Publish করুন:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /admissions/{applicationId} {
      allow create: if true;
      allow read, update, delete: if request.auth != null;
    }
  }
}

এর মানে: যে কেউ আবেদন জমা দিতে (create) পারবে, কিন্তু শুধু লগইন করা
অ্যাডমিনই আবেদনগুলো দেখতে/এডিট করতে পারবে।
