পাসওয়ার্ড রিসেট সমস্যার সমাধান হলো — দুটো ভাগে।

*** প্রথমে বুঝে নিন কেন দুই ধরনের সমাধান লাগলো ***
বেশিরভাগ অ্যাকাউন্ট মোবাইল নম্বর দিয়ে তৈরি — এদের কোনো real ইমেইল
নেই (ভেতরে ভেতরে একটা synthetic ইমেইল ব্যবহার হয়), তাই Firebase-এর
সাধারণ "ইমেইলে রিসেট লিংক পাঠান" পদ্ধতি এদের জন্য কাজ করে না। তাই:

১) মোবাইল নম্বর দিয়ে তৈরি অ্যাকাউন্ট (বেশিরভাগ) -> Admin সরাসরি
   নতুন পাসওয়ার্ড বসিয়ে দেবেন, তারপর ফোনে/সরাসরি জানিয়ে দেবেন
২) ইমেইল দিয়ে তৈরি অ্যাকাউন্ট (কম কমন, Admin নিজেও) -> Firebase-এর
   স্বাভাবিক "রিসেট লিংক ইমেইলে পাঠান" ব্যবস্থা কাজ করবে, সম্পূর্ণ
   স্বয়ংক্রিয়

Security Rules বদলানোর দরকার নেই।

=========================================================
১) Admin-এর মাধ্যমে পাসওয়ার্ড রিসেট (মোবাইল-ভিত্তিক অ্যাকাউন্টের জন্য)
=========================================================
Admin Dashboard -> "পাসওয়ার্ড রিসেট" কার্ড -> নাম বা নম্বর দিয়ে
খুঁজে সেই ব্যক্তিকে বেছে নিয়ে নতুন পাসওয়ার্ড দিন -> সংরক্ষণ করলে
নতুন পাসওয়ার্ডটা স্ক্রিনে দেখাবে, সেটা তাকে ফোনে/সরাসরি জানিয়ে দিন।

শুধু Student/Guardian/Teacher-এর পাসওয়ার্ড এখান থেকে রিসেট করা
যাবে — অন্য কোনো Admin-এর পাসওয়ার্ড এখান থেকে বদলানো যাবে না
(নিরাপত্তার জন্য)।

=========================================================
২) Firebase-এর স্বয়ংক্রিয় রিসেট (ইমেইল-ভিত্তিক অ্যাকাউন্টের জন্য)
=========================================================
Student/Guardian/Teacher এবং Admin লগইন — সব পাতাতেই এখন "পাসওয়ার্ড
ভুলে গেছেন?" লিংক আছে। ইমেইল দিয়ে লগইন করা কেউ এটা চাপলে সরাসরি
তার ইমেইলে Firebase-এর নিজস্ব রিসেট লিংক পাঠাবে। মোবাইল নম্বর দিয়ে
তৈরি অ্যাকাউন্টের ক্ষেত্রে এটা চাপলে স্পষ্ট বার্তা দেখাবে — "সরাসরি
যোগাযোগ করুন" (অর্থাৎ ধাপ ১ ব্যবহার করতে হবে)।

=========================================================
ফাইল বসান (৭টা)
=========================================================
সব Merge/Replace করে বসিয়ে push করুন।

=========================================================
টেস্ট করবেন যেভাবে
=========================================================
1. Admin দিয়ে লগইন করে "পাসওয়ার্ড রিসেট" কার্ডে গিয়ে কোনো একজন
   টেস্ট শিক্ষার্থীর পাসওয়ার্ড বদলান
2. লগ আউট করে সেই শিক্ষার্থীর নতুন পাসওয়ার্ড দিয়ে লগইন করে দেখুন
   কাজ করছে কিনা
3. /admin/login পেজে গিয়ে "পাসওয়ার্ড ভুলে গেছেন?" চেপে দেখুন (নিজের
   admin ইমেইল আগে বসিয়ে) — ইমেইলে রিসেট লিংক আসা উচিত
