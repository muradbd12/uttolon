=========================================================
ধাপ ১ — Firebase Console-এ Email/Password চালু করুন
=========================================================
1. console.firebase.google.com -এ গিয়ে আপনার "uttolon" প্রজেক্টে ঢুকুন
2. বাম পাশে Authentication -এ ক্লিক করুন
3. "Sign-in method" ট্যাবে যান
4. "Email/Password" -এ ক্লিক করে Enable করে Save করুন

=========================================================
ধাপ ২ — নিজের জন্য একটা অ্যাডমিন ইউজার বানান
=========================================================
1. একই Authentication পেজে "Users" ট্যাবে যান
2. "Add user" চাপুন
3. একটা ইমেইল (যেকোনো, যেমন admin@uttolon.com) ও পাসওয়ার্ড দিন
4. এই ইমেইল+পাসওয়ার্ড দিয়েই পরে /admin/login এ লগইন করবেন

=========================================================
ধাপ ৩ — Vercel-এ Environment Variables যোগ করুন (জরুরি)
=========================================================
আপনার .env.local ফাইলে যে ৬টা Firebase ভ্যালু + NEXT_PUBLIC_SITE_URL আছে,
ঠিক সেগুলোই Vercel-এ যোগ করতে হবে (এখন শুধু আপনার কম্পিউটারে আছে, Vercel
জানে না) —
1. vercel.com -এ uttolon প্রজেক্টে ঢুকুন
2. Settings -> Environment Variables
3. .env.local এর প্রতিটা লাইন Key/Value আকারে বসান, "Production" টিক
   দিয়ে Save করুন
এই ধাপ বাদ দিলে অ্যাডমিন লগইন কাজ করবে না (তবে এবার অন্তত পুরো সাইট
ভেঙে পড়বে না — একটা স্পষ্ট বার্তা দেখাবে)।
