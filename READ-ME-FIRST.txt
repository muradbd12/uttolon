Firebase Storage বাদ দিয়ে Cloudinary ব্যবহার করা হলো — কোনো
কার্ড/পাসপোর্ট লাগবে না, সম্পূর্ণ ফ্রি।

আগের uttolon-update-24.zip-এ যদি Storage-এর ধাপ (Console → Build →
Storage) করে না থাকেন, সেটা এখন আর করার দরকার নেই — বাদ দিয়ে দিন।

=========================================================
ধাপ ১ — Cloudinary-তে ফ্রি অ্যাকাউন্ট বানান (কার্ড লাগবে না)
=========================================================
1. cloudinary.com -এ যান, "Sign up for free" চাপুন
2. ইমেইল দিয়ে অ্যাকাউন্ট বানান (কোনো কার্ডের তথ্য চাইবে না)
3. লগইন করার পর Dashboard-এর উপরের দিকে "Cloud name" লেখা একটা
   জিনিস দেখবেন (যেমন dxxxxxxxxx ধরনের) — এটা টুকে রাখুন

=========================================================
ধাপ ২ — Unsigned Upload Preset বানান
=========================================================
1. Dashboard-এ Settings (⚙ আইকন) -> "Upload" ট্যাবে যান
2. নিচের দিকে "Upload presets" সেকশনে "Add upload preset" চাপুন
3. "Signing Mode" -> "Unsigned" করে দিন (এটা জরুরি — Signed রাখলে
   কাজ করবে না)
4. Preset-এর নামটা (যেমন ml_default বা আপনার দেওয়া কাস্টম নাম) টুকে
   রাখুন, "Save" চাপুন

=========================================================
ধাপ ৩ — Vercel-এ ২টা নতুন Environment Variable যোগ করুন
=========================================================
Vercel -> uttolon প্রজেক্ট -> Settings -> Environment Variables:

Key: NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME
Value: ধাপ ১-এর Cloud name

Key: NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET
Value: ধাপ ২-এর preset নাম

যোগ করার পর Deployments ট্যাব থেকে সর্বশেষটা Redeploy করুন (নইলে
নতুন env variable কাজ করবে না)।

=========================================================
ধাপ ৪ — ফাইল বসান
=========================================================
এই zip-এর ৩টা ফাইল Merge/Replace করে বসান।

=========================================================
টেস্ট করবেন যেভাবে
=========================================================
/admin/teacher-profiles -এ গিয়ে একটা শিক্ষক বেছে ছবি আপলোড করে
সংরক্ষণ করুন। ছবি ঠিকভাবে দেখালে কাজ হয়ে গেছে। কোনো সমস্যা হলে এবার
error message-এই আসল কারণ দেখাবে (Cloudinary কনফিগার করা না থাকলে
স্পষ্ট করে বলে দেবে)।
