Admission-এর সম্পূর্ণ প্রক্রিয়া আপডেট করা হলো। Security Rules বদলানোর
দরকার নেই — শুধু ৭টা ফাইল বসিয়ে push করুন।

=========================================================
আপনার প্রতিটা প্রশ্নের উত্তরে যা করলাম
=========================================================

১) "Documents নেই, কীভাবে নিশ্চিত হবে আবেদন করেছে"
   -> আবেদন জমা দেওয়ার সাথে সাথে এখন একটা সম্পূর্ণ রশিদ (Receipt)
   দেখাবে — নাম, বাবা-মায়ের নাম, ঠিকানা, স্কুল, প্রোগ্রাম সহ সবকিছু,
   প্লাস একটা Application ID। "রশিদ প্রিন্ট করুন" বাটনে চাপলে এটা
   PDF/কাগজে প্রিন্ট করা যাবে (ব্রাউজারের নিজস্ব Print ফিচার দিয়ে,
   কোনো বাড়তি খরচ ছাড়াই)।

২) "OTP Code নেই" — এই একটা জায়গায় honest থাকা দরকার:
   সত্যিকারের SMS OTP বাংলাদেশে বিনামূল্যে হয় না — প্রতিটা SMS-এর
   জন্য একটা গেটওয়ে সার্ভিসকে টাকা দিতে হয় (যেমন SSL Wireless, Alpha
   SMS)। যেহেতু আপনি সবকিছু ফ্রি রাখতে চেয়েছিলেন, তাই real OTP এখানে
   যোগ করিনি। এর বদলে যেটা করলাম সেটা কার্যত একই কাজ করে বিনামূল্যে:
   রশিদ + Application ID (প্রমাণ), আর Admin-এর ম্যানুয়াল
   review/confirm ধাপ (নিচে ৩ নম্বরে)। ভবিষ্যতে কখনো একটা paid SMS
   API যোগ করতে চাইলে সেটা আলাদা একটা ধাপ হিসেবে করা যাবে।

৩) "শুধু নাম দেখাচ্ছে, প্রোফাইল চেক করা যায় না"
   -> Admin -> ভর্তি আবেদন পেজে এখন প্রতিটা আবেদনে ক্লিক করলে পুরো
   তথ্য (জন্ম তারিখ, বাবা-মায়ের নাম, ঠিকানা, স্কুল, গ্রুপ, পূর্ববর্তী
   ফলাফল, দুর্বল বিষয়, ব্যাচ পছন্দ) খুলে দেখা যাবে।

৪) নতুন যোগ করা — ভর্তি নিশ্চিতকরণ ধাপ:
   প্রতিটা আবেদনে এখন "ভর্তি নিশ্চিত করুন" বা "প্রত্যাখ্যান করুন"
   বাটন আছে। নিশ্চিত করার পর একটা নতুন বাটন আসবে — "লগইন অ্যাকাউন্ট
   তৈরি করুন" — এটাতে চাপলে সরাসরি অ্যাকাউন্ট তৈরির পেজে চলে যাবে,
   এবং নাম/ক্লাস/গার্ডিয়ানের নম্বর/মোবাইল আগে থেকেই পূরণ করা থাকবে
   (আবার টাইপ করতে হবে না)।

৫) বাড়তি একটা জিনিস নিজে থেকে ধরে ঠিক করেছি:
   টেস্ট করতে গিয়ে দেখলাম, ইন্টারনেট/সার্ভার সমস্যা হলে ফর্ম
   অনির্দিষ্টকাল "জমা হচ্ছে..." দেখিয়ে আটকে থাকতে পারতো, কোনো error
   ছাড়াই। এখন ১৫ সেকেন্ডের মধ্যে সাড়া না পেলে স্পষ্ট error message
   দেখাবে। Admission ও Scholarship — দুটো ফর্মেই এটা যোগ করা হয়েছে।
